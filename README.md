# Multi-Language Banking System 🏦

A simple command-line banking system that supports three languages:

🇬🇧 **English**  
🇲🇭 **Marathi (मराठी)**  
🇮🇳 **Hindi (हिन्दी)**  

This program allows a user to:
- Create an account  
- Debit money  
- Credit money  
- Delete an account  
- Continue multiple transactions  
- Switch languages

## 💡 How It Works
1. User selects language  
2. Program displays menu in selected language  
3. User chooses a task  
4. Account details are processed  
5. User is asked if they want to continue  
6. Repeats until the user exits
